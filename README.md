# sandelz-site

This folder contains a simple static website ready for GitHub Pages.

## Files

- `index.html` — homepage
- `info.html` — info page
- `dark.html` — dark XP-style page

## Publish on GitHub Pages

1. Install Git on your computer.
2. Open a terminal/PowerShell and run:

```powershell
cd C:\Users\jokke\sandelz-site
git init
git add .
git commit -m "Initial site"
```

3. Create a GitHub repository and push the code.
   - If you use GitHub Pages from the `main` branch root, push to `main`.
   - If you use a user site, name the repo `yourusername.github.io`.

4. Enable GitHub Pages in the repository settings and choose the `main` branch as the source.
